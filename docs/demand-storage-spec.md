# 0.3.0 顾客需求高亮与分页标签收纳

## 已确认行为

需求高亮默认启用，H 切换并全局持久化；当前交谈顾客变化时自动刷新，不按预算过滤。直接匹配显示内缩边框，容器包含匹配物品显示角标，和赃物／违禁品标记共存。

J 按下时处理当前选区，持续按住并点击时只处理该次点击物品，不进入拖动、不因长按自动重复。空选区单独按键无动作。配置中可关闭或改键。

容器标题栏设置图标编辑名称、搜索标签、任意／全部匹配和整数优先级。名称为完整 Mod 别名，不改游戏原生物品类别；每个升级储藏页独立配置。规则按容器 uniqueId 与从零开始页号保存到当前 run 的 ModData。首次保存规则才为未分配身份的容器分配 uniqueId。

Open 仅包含当前可见的页；All 包含玩家主库存内的合规拥有容器及嵌套储藏全部页。排除待售／交易／顾客、垃圾及机器输入口。扩展储藏保持原网格为第0页，新页单独网格；只读取页面，不调用 Select。旧明确目标转移仍只使用玩家选中的当前页。

优先级降序，同级容器身份、页号升序。满则尝试下一个，可拆堆叠；无匹配或空间不足留原处，提示未收纳数量。已位于匹配目标中的物品保持原位。固定物品及带标签的容器跳过（包括锁定后仍有标签者）。未贴标签容器按自身属性整只移动，内容不拆出；遵守原生限制，不允许放入自身或后代。无标签容器的手动放入和旧快捷转移不受影响。

## 实际匹配与兼容边界

- 普通顾客：原生 IsClientBuyingThisItem；不调用 HasBudgetLeftToBuy。
- 枪械订单：ADV_GUN_TAG 与 mandatoryRequirements；维修只匹配指定 serviceGun 实例。
- 条件易货：BarterCondition.IsItemValid。
- 当前正式版特殊采购／易货：精确识别经 IL 验证的原生闭包，匹配 pink_injector、moonshine、FOOD、blood_bag、metal_ingot。表示可贡献物品，不表示整单数量满足。未知回调不推测，提示无法识别。
- 标签：游戏分类全目录、公开条件目录，以及已验证的冷藏／冷冻／冰冷、赃物、违禁品及其等级、无法使用等离散状态。条件采用物品界面当前公开状态，不以隐藏真假做匹配。
- 用户确认本次不做耐久、纯度等数值条件。特定物品／其他 Mod 自定义的自由文本描述不自动转成标签。
- 原生分页名称接口限12字，本功能使用独立别名保存完整输入。标题可能受窗口空间限制，完整名称在编辑器查看。
- 当前运行时冲突检测覆盖公开游戏绑定、储藏协调器预设及已知硬编码 T；其他 Mod 自行轮询按键无法保证识别。

## 自动验证与实机验收

自动验证：Build.ps1 正式版编译；Organizer.Tests 逻辑检查；Test-GameBindings.ps1 绑定检查。逻辑替身不运行 Unity 或游戏回调。

仍需使用测试存档在游戏内检查：

1. 普通箱包和升级储藏的设置图标位置、点击、搜索滚动、保存／取消／Escape；长中文名和语言切换。
2. 第1页配武器、第2页配食物；Open 仅当前页，All 可收进隐藏页且不切页；每页满后按优先级换目标。
3. 先给未升级储藏配规则，再升级，原页规则保持，新页无规则；保存重启与不同存档切换无串用。
4. 多选按 J、按住 J 连续点、先放开 J 再放开鼠标、拖动时按键、输入框键入、改键冲突，不触发原生拖动或其他快捷操作。
5. 固定／锁定／已贴标签容器、嵌套和禁止自包含、非法枪械或化学物品；满空间与拆堆叠，无丢失或复制。
6. 普通收购、枪械维修／订单、特殊易货／采购、下一位顾客、手动关闭与重启记忆；旋转物品、嵌套角标、风险标记同时显示。
7. 停用 Mod、离店、读档后无遗留标题、按钮和标记；手动放入及原有转移正常。

未自动部署、启动游戏或上传 Workshop。
