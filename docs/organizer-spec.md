用户于 2026-10-29 确认开始实现与编译。本文件优先于 input-research.md 中的早期建议。

0.2.0 名称改为 Better Hotkeys / 更好的快捷键，作者 FIELD9z。以下快捷键描述为默认配置；可自定义项及原生兼容模式以 [中英文使用说明](user-guide.md) 为准。保留内部 ID 与已有 sort_big_first、sort_from_end 配置键。

## 范围

店内、自有、原生允许操作的物品；不接管外出、交易／未购买物品、机器专用槽位的新快捷动作。2026-10-29 用户要求清除原快速转移逻辑：Mod 启用时统一禁用原 Shift/Ctrl/Alt 快速转移，不再在范围外回退；普通拖动等其他原生行为保留。停用 Mod 后恢复原快速转移。用户已授权打包修复后直接安装，安装前检查游戏退出；不自动启动游戏或上传 Workshop。

## 快速转移

| 来源 | Shift＋单击 | Ctrl＋单击 |
| --- | --- | --- |
| 玩家主库存 | 出售柜台 | 最近点击且仍有效的已打开容器 |
| 出售柜台 | 玩家主库存 | 不转移，提示路线 |
| 自有已打开容器 | 出售柜台 | 玩家主库存 |

库存不包括库存中箱包内部空间。无目标、目标满或受限制时不绕路，不自动整理目标腾空间。允许部分堆叠接收，剩余留在来源并反馈数量。

目标容器持续高亮标签栏。实际点击容器才切换目标，悬停标签栏整理不切换。关闭、失效或不可访问即清除，不自动选其他容器或自动恢复。

2026-10-29：正常完整转移不再提示；无目标、失败、部分成功或有跳过项仍反馈。

## 赃物与违禁品标记（0.1.4，待游戏内验证）

用户选择：双击一个按键开关标记；仅标记外层容器，打开后标记内部命中物品或下一层容器，不显示路径列表。多层嵌套需要递归检测，分类分别显示赃物、违禁品及同时符合两者的物品。标记不移动或改变物品，不等于“一定会被盘查发现”。

用户最终选择双击 B（0.35 秒内两次按下），再次双击关闭。黄框为赃物、红框为违禁品、紫框为两类都有；外层容器汇总内部所有分页和嵌套内容。扫描已显示的店内窗口及其内容图，只给可见物品添加边框，每 0.2 秒刷新。不自动打开容器、不修改原生多选或固定状态。

文字输入、改键、模态阻挡、书本编辑、选项对话及拖动时不触发；检查当前 KeyBindHelper 和可用储藏协调器预设是否占用 B，冲突则提示并不切换。离店、读档、停用时清除。不得调用会修改热度或进行盘查的 SecurityCheckCounter / InspectItem 等方法进行纯显示扫描。

点击选区内的物品时批量操作，只处理与被点击物品处于同一直接来源的选中物品。按上到下、左到右稳定顺序尝试；失败跳过继续，汇总移动、剩余及跳过数量。移走的退出选区，未移走或部分移走的保持选中，其他来源的保持不动。点击选区外只操作该物品。

固定物品不转移，必须先解除固定。箱包可按原生规则整体转移，不倒出内容，不放入自身或后代容器。

## 固定与鼠标手势

- 左右 Alt＋单击切换固定；范围与原生固定条件不变，保留 P 模式。
- 点击选区内，以被点击物品原状态决定统一固定／解除固定，同一来源批量执行，保持选区。不可固定项跳过并说明。
- Alt 拖动超过阈值时不固定也不移动，取消该次手势。**移除范围内 Alt 拖动取单个的行为。**
- 左右 Shift／Ctrl 均支持。先按修饰键再单击，鼠标释放时仍保持才能执行；同时按多个修饰键时不执行快捷动作并提示。
- 进入拖动后不补发转移。普通拖动、Shift 开始拖动取半堆与滚轮调整保留。
- 文字输入、改键及阻挡物品操作的模态界面中不触发新快捷动作。

## 数量调整

原拟新增 T 单取键；静态核查发现 `SmoothMouseMovement.Update` 已读取 T，用户随后明确取消独立单取键。不增加单取动作、改键项或原生 T 屏蔽补丁。Alt 仍仅固定，数量调整使用原生滚轮和 Shift 拖动半堆。

## 整理

鼠标悬停容器标签栏，按当前原生整理绑定（默认 S）立即整理该容器。内部原有 S 菜单行为保留，不递归、不整理其他容器。

首次采用大件优先、从起始端排布；自动旋转沿用游戏设置。以后全局记住最近在原生整理菜单选择的方式。

复用原生算法，整理撤销仅保留原菜单能力；不新增撤销键、不实现跨容器转移撤销。

## 验收

编译、纯逻辑测试与实际游戏内验证分别记录。游戏内必须覆盖上述三来源路线、满容量／部分容量、多容器、固定与混合选区、单取、点击／拖动阈值、输入焦点、模态窗口、离店／回店及启停清理。不把编译通过描述为游戏内通过。
