[h2]Installation and controls[/h2]
For the full release of Probably Stolen. Subscribe, enable in Mods and restart when prompted.
Shift + left click: inventory/container to sales counter; counter to inventory.
Ctrl + left click: inventory to the highlighted open container; container to inventory.
Alt + left click: pin/unpin; supports selections sharing the same source.
Hover a header + S (or the game's sort key): sort that container.
Double B: toggle stolen/contraband markers, including nested contents.

[h2]Quick storage and customer demand[/h2]
[b]D[/b]: toggle customer-demand highlights.
[b]C[/b]: store selected items by rules, or hold C and left-click items. All eligible pages are checked by default, including closed storage windows.
Use a container header's gear to configure names, priorities, allowed/denied items and allowed/excluded tags. Allowed tags support any/all matching. Any excluded tag rejects the item, even if it is explicitly allowed. Item allowlists route before tags; pinned items are not moved automatically.
Inspect items in the Tags tab and collect visible tags into either list. Right-click to finish picking; Save commits the draft. Opening the editor collapses the side preview.
Manual destinations with rule conflicts offer matching-only transfer, an override, or cancellation. Overrides still respect native capacity, locks and type restrictions.
Native shortcut hints remain intact. An independent shortcut guide is available at the bottom of the mod settings.
