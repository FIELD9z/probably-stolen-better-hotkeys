[h2]更好的快捷键与收纳 / Better Hotkeys & Storage 0.5.3[/h2]
按规则收纳物品，快速转移，轻松找到顾客要的东西和藏起来的赃物。

[h2]功能[/h2]
[list]
[*]规则收纳：按物品或标签分流，支持跨容器、跨分页收纳。
[*]独立分页：每页可设置名称、接收规则和优先级，默认检查全部合规分页。
[*]黑白名单：允许食物、排除赃物，或指定只收某些物品；拒绝规则优先。
[*]分类选择：物品按游戏类别展开浏览，标签按类别、属性和状态分组，寻找规则更方便。
[*]拼音搜索：物品和标签支持中文、英文、拼音首字母和全拼搜索。例如“手枪”可以搜 sq 或 shouqiang，搜索覆盖全部分类。
[*]已选规则管理：允许和排除名单独立显示，不受搜索或筛选影响；可逐项移除，也可分别清空，保存后生效。
[*]标签采集：点选物品查看可见标签，快速加入规则。
[*]容器互转：先点击目标容器，再 Ctrl 点击其他容器里的物品即可转入；快捷操作不会改变已选目标。
[*]设备成品收纳：支持从设备独立成品区快捷取出，送往库存、指定容器、出售柜台，或按规则自动收纳。
[*]快捷整理：悬停容器标题栏即可整理。
[*]需求高亮：高亮顾客需要的物品，容器角标提示内部有匹配物品。
[*]赃物与违禁品标记：定位赃物和违禁品，支持查看嵌套容器。
[*]批量固定：固定重要物品，快捷转移和自动收纳不会搬走它们。
[*]中英双语：支持跟随游戏语言，也可手动切换。
[/list]

[h2]收纳怎么用[/h2]
点击容器标题栏齿轮 → 设置允许物品或标签 → 保存 → 选中物品按 C。
例如：食品页允许“食物”，排除“赃物”；材料页允许“材料”。
固定、没有匹配目标或放不下的物品留在原处。

物品目录会记住当前存档中曾在打开窗口里显示的自有物品，卖掉后仍可搜索；未打开容器里的内容不会提前收录。也可以继续直接点选实物来添加规则。

[h2]默认键位[/h2]
可在游戏 Mods 中打开本 Mod 设置调整快捷键。更新会保留已有按键设置，实际键位以设置页为准。
[list]
[*]C：收纳选中物品；也可按住 C 连续左键点选。
[*]D：开关顾客需求高亮。
[*]双击 V：开关赃物／违禁品标记。
[*]Shift＋左键：库存／容器／设备成品区 → 出售柜台；柜台 → 库存。
[*]Ctrl＋左键：库存、其他容器或设备成品区 → 已高亮的目标容器；点击目标容器里的物品则取回库存。没有目标时，容器和成品区里的物品返回库存。
[*]Alt＋左键：固定／解除固定，支持同来源选区。
[*]悬停容器标题栏＋S：整理该容器（跟随游戏整理键）。
[/list]

普通左键点击已打开的自有容器即可选定目标，也可在设置中改为仅点击标题栏指定。关闭目标窗口或切换其分页后，需要重新选定。

设备转移仅支持有独立成品输出区、且游戏允许取出的物品；不包括原料、燃料或加工中的物品，也不会自动向设备投料。

[h2]安装[/h2]
订阅本 Mod，在正式版游戏 Mods 菜单启用并按提示重启。
